# 11月分進捗
## 操作方法
WASDで移動。  
Rで武器の入れ替え、Lで敵をロックオン、Pでガード  
Oで上昇、Eでリロード、矢印キーでロックオン先変更
## 今月の成果一覧
- 剣
  - 剣の挙動を完成させ近接攻撃もできるようになった
- 銃
  - 銃のリロードを追加して最大の弾数を設定
- プレイヤー移動
  - Oキーを押すことでプレイヤーが上昇する上昇は数値で測って上限になったら降下する  
  Oキーを押していないときは下降し、数値も下がる
- エネミーの移動
  - 敵を何もしない状態からプレイヤーに向かって弾を撃つようにしたのとプレイヤーに向かって移動し必ずプレイヤーの周りを囲むようにしました
## その他
先月に比べてプレイヤーのある程度の動きを完成させましたまだ少しプレイヤーの剣の攻撃当たり判定を修正しなきゃいけないのとキー配置をもう少し考えなきゃいけないのと敵がプレイヤーに向かって動く処理がプレイヤーが空中に行ったとも一緒に向かってしまうのである程度近づいてから上昇に書き換えなきゃいけないなと思いここからUIとパーティクルも入れていきたい思いました
